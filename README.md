# Veloura Cafe Website

Website cafe responsif menggunakan HTML, CSS, dan JavaScript murni.

## Menjalankan
1. Ekstrak file ZIP.
2. Buka folder `veloura-cafe` di VS Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server.

## Kustomisasi
- Nama cafe, alamat, jam buka, dan teks: `index.html`
- Warna, layout, dan responsive design: `style.css`
- Interaksi tab menu, navigasi mobile, dan animasi: `script.js`

Catatan:
- Foto diambil dari URL Unsplash dan membutuhkan koneksi internet.
- Harga menu, alamat, jam buka, dan identitas cafe masih berupa contoh.
- Ganti tautan Google Maps dengan lokasi cafe sebenarnya sebelum dipublikasikan.
